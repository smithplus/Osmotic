OSMOTIC: INSTALL
=================

1. Drag Osmotic onto the Applications folder.
2. Open it from Applications.

The first time, macOS says it can't verify Osmotic. That's because this
build isn't notarized by Apple (the project has no paid Apple Developer
account yet). To open it anyway:

   System Settings › Privacy & Security › scroll down › "Open Anyway"
   (next to the message about Osmotic), then confirm with your password.

You only do this once. Later versions install themselves from GitHub
(Osmotic › Check for Updates…), after checking their signature.

Source code, help and issues: https://github.com/smithplus/Osmotic
