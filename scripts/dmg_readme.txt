OSMOTIC — INSTALL
=================

1. Drag Osmotic onto the Applications folder.
2. Open it from Applications.

The first time, macOS may say it can't check Osmotic for malicious software.
That's because this build isn't notarized by Apple (the project has no paid
Apple Developer account yet). To open it anyway:

   System Settings › Privacy & Security › scroll down › "Open Anyway"
   (next to the message about Osmotic), then confirm with your password.

You only do this once. Later versions install themselves from GitHub
(Osmotic › Check for Updates…), after checking their signature.

Source code, help and issues: https://github.com/smithplus/Osmotic


OSMOTIC — INSTALACIÓN
=====================

1. Arrastrá Osmotic a la carpeta Aplicaciones.
2. Abrila desde Aplicaciones.

La primera vez, macOS puede decir que no pudo verificar Osmotic. Pasa porque
esta build no está notarizada por Apple (el proyecto todavía no tiene cuenta
paga de Apple Developer). Para abrirla igual:

   Ajustes del Sistema › Privacidad y seguridad › bajá hasta el final ›
   "Abrir igualmente" (junto al aviso de Osmotic) y confirmá con tu contraseña.

Se hace una sola vez. Las versiones siguientes se instalan solas desde GitHub
(Osmotic › Buscar actualizaciones…), después de verificar su firma.

Código, ayuda y reportes: https://github.com/smithplus/Osmotic
