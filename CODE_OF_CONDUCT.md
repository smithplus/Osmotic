# Code of conduct

This project is small and the rule is simple: be decent to each other.

**Expected:** stay on the technical question, take feedback at face value, credit other people's work (this app is built on plenty of it).

**Not welcome:** insults, harassment, discrimination, posting other people's private information, or derailing threads.

## If something goes wrong

Open an issue, or ask for a private channel in an issue without details. The maintainer reads every one and will act: a reply, an edit, a locked thread, or a block, depending on what happened.

Security problems have their own path: [SECURITY.md](SECURITY.md).
